# v1.0.1 변경 및 적용

- 홈 이어가기와 하단 연습 메뉴는 마지막 위치를 복원합니다. 곡 목록은 0초에서 시작합니다.
- 같은 곡 화면에 입장한 뒤 실제 재생 누적 60초에 1회 기록합니다. 정지·대기 시간은 제외하며, 같은 입장에서 2분·3분을 재생해도 횟수는 추가되지 않습니다. 모드 전환은 누적을 유지합니다. 음원 뒤 응원 연습 구간의 진행도 연습 시간에 포함합니다.
- 기존 저장 기록은 보존합니다. 과거 기록에는 재생 여부가 없으므로 이전 횟수를 새 규칙으로 재계산하지 않습니다.
- 힌트의 ○는 CSS로 작은 핑크레드 채움 원으로 표시합니다. 원본 힌트 문자열과 공백은 그대로입니다. Studio는 이번 수정 범위에 포함하지 않았습니다.
- 음원 개별/전체 삭제 버튼을 제거했습니다. 재설치와 설치 상태/용량 표시는 유지합니다.
- 안내 문구에서 다운로드 제공업체 이름을 제거했습니다. 다운로드 링크는 동일합니다.
- 음원 종료 뒤 위치를 이어갈 때는 미디어 메타데이터 로딩을 기다리지 않고 무음 구간을 복원합니다.

소스 ZIP을 기존 저장소에 덮어쓴 뒤 아래 명령을 실행합니다. .git 폴더는 유지하고 브라우저의 사이트 데이터는 지우지 마세요.

```powershell
npm ci
npm test
npm run build
git add .
git --no-pager diff --cached --stat
git commit -m "Refine resume flow and one-minute practice counting"
git push origin main
```

GitHub Actions에서 build/deploy 성공을 확인한 뒤 사이트를 새로고침합니다. 설정의 앱 버전은 1.0.1, 콘텐츠팩은 그대로 2.0.0입니다. 새 음원팩이나 콘텐츠팩을 설치할 필요가 없습니다.

추가 권장: 재생 완료 위치는 홈에서 '다시 연습'으로 안내하고, 일반 사용자의 설정 화면에서는 곡별 표시/이벤트 개수 진단을 접어두는 것이 좋습니다. 이번 버전에서는 이 두 UI 변경을 적용하지 않았습니다.

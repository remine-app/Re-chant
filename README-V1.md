# Re:chant Web v1.0.0

Studio v0.10 런타임 콘텐츠를 표시하는 연습 앱입니다. 최신 콘텐츠 11곡은 public/content에 포함되어 있습니다. MP3는 별도 음원팩을 브라우저에 설치합니다.

실행: `npm ci` → `npm test` → `npm run dev`.

배포 빌드: `npm run build`. GitHub Pages는 `.github/workflows/deploy-pages.yml`이 담당합니다.

배포와 Git 업로드: [안내](docs/UPDATE_AND_GIT_KO.md)

데이터 계약: [계약](docs/RUNTIME_CONTRACT.md)

기존 README-v0.2.1.md, PRACTICE-UPDATE.md, VERIFICATION-v0.3.0.md와 구형 e2e/app.spec.ts는 이전 버전의 참고 자료입니다. 현재 동작과 검증 결과는 본 문서와 docs 아래 문서를 우선합니다.
